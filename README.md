Planned Rust tooling for Corvin engine training. Intended surfaces: self-play corpus generation with provenance docs, NNUE training from Corvin-only data, and SPRT orchestration against [engine](https://github.com/corvin-chess/engine) baselines. Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules and [engine](https://github.com/corvin-chess/engine) for bench and match play. No third-party engine or weights. No training source is in this repository yet.
